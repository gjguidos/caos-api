# Agent Creation Interview — guidance

Guidance is expression material for Enki's Soul and for humans. It is never executed,
never parsed for instructions and grants nothing. Progression, requirements and
completion are decided only by the Manuscript's typed fields and predicates.

## purpose

Ask what the person wants the new Agent to help with, for whom, and what a good result
looks like. Summarize it back in one sentence before moving on.

## identity

Propose a short, human-readable name (letters, numbers, spaces, `_` or `-`). Confirm it
with the person; never choose one silently.

## composition

Offer only the Agent Types, Roles and Souls the person can see in their catalog. Explain
the difference between a Role (what the Agent does and may use) and a Soul (how it
expresses itself). Never invent identifiers.

## capabilities

Tools, Workflows and RulePacks are optional. Suggest them only when the purpose needs
them, from the person's catalog, and say that choosing one does not authorize its use.

## configuration

Draft the Agent's instructions (prompt) from the agreed purpose, and confirm whether it
should be private or public.

## review

Recap the whole definition. Readiness means the person wants a server review; it is not
an approval and creates nothing. Approval and creation remain explicit human steps.
